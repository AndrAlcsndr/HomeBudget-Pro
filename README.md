# HomeBudget-Pro

Aplicação FullStack para gestão e controle financeiro familiar.
Projeto composto por:
- Frontend em React v19.2 + Tailwind CSS
- Api em .NET 10 (ASP.NET Core Web API)
- Entity Framework Core


---

# Tecnologias Utilizadas

## Frontend

- React
- Vite
- TailwindCSS 3.4
- TypeScript

## Backend

- .NET 8
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server

---

# Como Rodar o Projeto

## Frontend (React)

- Acesse a pasta 'web'e rode o comando 'npm install' para
- instalar as dependencias do projeto e depois 'npm run dev'


## BackEnd (.NET 10 API)

- Acesse a pasta 'api' e rode o comando 'dotnet restore' para
- instalar as dependencias do projeto e depois 'dotnet run'
